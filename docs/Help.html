No. Series Manager

Create date-based No. Series Lines ahead of time from a pattern, so posting never stops because a period has no line.

Create No. Series Lines

  1. Open No. Series and select a number series.
  2. Choose Processing > Create No. Series Lines. The action is also on No. Series Lines.
  3. Fill in the fields below and choose OK.
FieldDescription
PatternTokens followed by the starting number, for example CCYY-10000.
CadenceHow often a new line is created: Day, Week, Month, Quarter or Year.
Start DateThe date the first line starts on. Lines are created for one year from this date.
Increment-by No.The number to increment by when a new number is assigned.
Warning No. OffsetHow many numbers before the ending number a warning is given. 0 means no warning number.

Pattern tokens

TokenReplaced with
CCCentury
YYYear (2 digits)
MMMonth (2 digits)
DDDay (2 digits)
WWWeek number (2 digits)
QQuarter (1–4)

All other characters are kept as typed. Each period must get a unique prefix, so use tokens that change with the chosen cadence.

Notes

  • Periods that already have a line (same starting date or starting number) are skipped.
  • The pattern setup is saved per number series.
  • Assign NSMGR NSHLG, EDIT to users who create lines.
